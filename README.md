# 徳島いこか

2026/10/29〜31 の鳴門旅行（6人）用の旅程共有アプリ。

- 日別タブのタイムラインで「次どこ行くんだっけ」を解消する
- 予定ごとに参加者が違う（1日目は5人、2日目の朝に1人合流）ので、自分の予定と他の人の予定を左右に振り分けて表示する
- 各予定に1タップで「済」を付けられる。誰が押したかも出る

## 技術

- Vite + TypeScript + React
- Firestore（合言葉＝同期コード方式。合言葉がそのままコレクションのパスになる）
- GitHub Pages で公開

## 開発

```bash
npm install
npm run dev
npm run build
```

## 合言葉

`firestore.rules` の `'ここに合言葉'` を実際の文字列に置き換えて、Firebaseコンソールのルールに貼る。
実際の文字列は `合言葉.txt`（Git管理外）に控えてある。
